这一版做了什么

  • 词库 6.5 万 → 31.7 万 以 Unihan 通用规范汉字表 + jieba 语料词表重建词库：8703 个单字（含多音共 11825 条读音）、317258 条词， 字频按真实语料排序（了 / 是 / 在 / 和 / 有 / 他 / 不 / 我 / 的 / 人）。 首屏只同步加载核心分片，其余 5 个分片在空闲时用本地 <script> 逐个并入并增量建索引， 打字时随用随扩，不阻塞输入。
  • 手写识别重写 两阶段检索（分布特征粗筛 → 48×48 双向倒角 + 8×8×4 方向图细评），特征做「墨迹分布归一化」， 笔画粗细不再影响打分；模板覆盖楷体/黑体/仿宋三种字形，单字模板压缩成位图 + 量化特征。 同一套回归测试下 top1 从约 42% 提升到 91.4%、top5 99.3%，单字识别约 28ms， 字库从 4520 扩到 6500 字。
  • 上下文重排 手写候选会参考输入框里上一个字：例如上文是「重」，候选里「庆」会被提前， 因为词库里存在「重庆」这个词。
  • 越用越准 点选过的候选字会记录在本机（localStorage），同字下次自动前置；选词记忆、自造词、短语、设置同样本地持久化。
  • 8 种模式 拼音 / 英文（带单词补全）/ 数字 / 符号 / 表情（7 组约 170 个）/ 手写 / 短语（可增删）/ 工具。
  • 工具面板 复制、剪切、粘贴、全选、撤销、光标左右/行首行尾、长按字母出数字符号、 简拼与模糊音开关、候选每页 6/8/10、手写自动识别开关、深色主题、输入统计。

快捷操作

  • 空格 上屏首选词 · 1~9 直接选第几个候选 · Esc 收起键盘
  • 长按字母键 0.4 秒 → 弹出该键对应的数字与常用符号
  • 长按 ⌫ 与 ← → 连续触发
  • 手写区：停笔 0.2 秒自动识别，右侧可翻页，点「更多 ▾」一屏看 32 个候选字
  • 想验证识别准确率：打开手写回归测试页（本机跑，离线）
