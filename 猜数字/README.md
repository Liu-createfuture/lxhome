# 猜数字 · 4 位 1A2B

一个可以直接玩的双模式猜数字游戏：**单人练习** + **联机对战房间**。

## 快速开始

```bash
npm install     # 首次运行需要（只有 ws 一个依赖）
npm start       # 默认 http://localhost:3000
```

启动后终端会同时打印局域网地址，例如 `http://192.168.1.8:3000`，
把这个地址发给同一个 WiFi 下的朋友，就能一起联机。

换个端口：`PORT=8080 npm start`

## 玩法

系统生成一个 4 位数字，每一位互不相同（首位可以是 0）。每次输入 4 位数字：

- **A**：数字对、位置也对
- **B**：数字对、位置不对
- `4A0B` 即破解成功

## 两种模式

**单人练习**
- 每次开始随机出题，实时显示已猜次数、用时、以及"剩余可能"（根据历史反馈推算还有多少种答案）
- 支持键盘操作：输入自动跳到下一位，`Backspace` 回退，`Enter` 提交
- 对局记录存在浏览器本地（localStorage），可展开查看每一次猜测，随时清空

**联机对战**
- 创建房间 → 得到 4 位房间号 → 把房间号或邀请链接发给朋友
- 两人就位后由房主点击开始，3 秒倒计时后同时抢答
- 双方使用**同一个答案**，先猜中的人获胜；实时显示对手已猜次数
- 中途刷新页面会自动回到原来席位（席位保留 90 秒，超时判负）
- 支持快捷表情、再来一局
- 同一浏览器开两个标签页就能自己测试：一个创建房间，另一个用邀请链接进入（每个标签页是独立玩家）

## 目录结构

```
server.js          HTTP 静态服务 + WebSocket 房间管理（纯 Node，仅依赖 ws）
public/
  index.html       页面结构
  styles.css       样式
  app.js           单人逻辑 + 联机客户端
test/
  e2e.js           联机端到端测试（创建房间、加入、判分、重连、结算）
  ui-shot.js       用 CDP 驱动无头浏览器模拟两名玩家并截图
```

## 测试

```bash
# 终端 1：用固定答案 8374 起一个测试实例
GN_SECRET=8374 PORT=3100 node server.js

# 终端 2
GN_SECRET=8374 node test/e2e.js
```

## 说明

- 房间数据保存在内存中，重启服务即清空；同一房间上限 2 人
- 猜数字的判定在服务端完成，联机模式下前端拿不到答案
